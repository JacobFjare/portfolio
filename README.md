# Portfolio

Temporary README for a Next.js portfolio site.

## Development

```bash
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Structure

- `src/app` contains the Next.js route and layout.
- `src/components/portfolio` contains the portfolio sections and styles.
- `src/data/portfolio.ts` contains editable placeholder content.
- `public/images` contains static image assets.
